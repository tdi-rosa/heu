# Demandes des joueurs

Cette pull request reste ouverte comme boîte de réception pour les demandes envoyées depuis le jeu. Ne pas la fusionner. Les commentaires `[heu-request]` contiennent les demandes ; ChatGPT les traite et publie les changements sur main. Les statuts sont mis à jour dans le commentaire original. Aucun secret ne doit apparaître ici.
